# 🌊 BlueWave CMS

A full stack CMS-style web application developed in PHP and MySQL, featuring a dynamic front-end and a custom backoffice for content management.

## 🚀 About the Project

BlueWave started as a final project during my Full Stack Web Development training and evolved into a complete content management platform.

The project combines a responsive public website with a custom-built administrative dashboard where content can be managed dynamically through a database-driven system.

The goal was to gain practical experience building a real-world application from planning and database structure to user interaction and content management.
